# Project Context: Web Tu van Nong nghiep (User - Admin - Partner)

## 1. Tong quan du an
He thong web tu van truc tuyen (mo phong giao dien kieu Zalo chat, theme xanh duong Zalo #0068FF):
- **User (Khach hang)**: Dang ky, dang nhap, chat rieng voi Admin va chat rieng voi Partner (neu duoc gan), gui kem anh/tai lieu. Tu ghi **nhat ky canh tac** (hoat dong, ngay, phuong phap, chi tiet, anh) va xem timeline cua minh.
- **Admin**: Sidebar quan ly danh sach user can tu van (kem badge unread + badge partner + so muc nhat ky), khung chat truc tiep voi khach, tab chat rieng voi partner, gan "Ben thu 3" (Partner) cho user, xem nhat ky canh tac cua khach, bat/tat **Bot AI** (tu dong tra loi khach) cho tung khach bang toggle.
- **Partner (Ben thu 3)**: Dang nhap, xem danh sach khach hang duoc admin gan, xem **nhat ky canh tac**, va nhan tin rieng voi khach + rieng voi admin. Khong thay duoc chat admin↔khach; khong tao/xoa duoc nhat ky.
- **Bot chuyen gia nong nghiep ("Tro ly AI")**: User ao `ai-bot` (role bot, khong login duoc, khong hien trong sidebar admin). Khi khach nhan trong thread user_admin va `bot_enabled=1`, bot tu dong tra loi: rule-based offline (knowledge base 12 chu de tieng Viet, tu dung ky tu khong dau) hoac LLM streaming (Gemini/OpenAI-compatible qua env). Thu tu tra loi: LLM chinh → LLM fallback (`LLM_FALLBACK_*`) → LLM fallback 2 (`LLM_FALLBACK2_*`, mac dinh Groq) → rule-based; ngoai gio hanh chinh (`OFFICE_HOURS`) bot tra thong diep hen phan hoi; khi bot khong chac (cau tra loi la KB fallback), server phat `bot-unsure` toi room admin de nhan vien vao tu van.

## 2. Tech Stack
- **Backend**: Node.js + Express + Socket.io (WebSocket chat real-time, path: /ws; client bundle nam tai `/ws/socket.io.js`).
- **Database**: SQLite qua better-sqlite3 (file `data/app.db`, module db.js) gom 5 bang: users, conversations, messages, process_entries, sessions.
  - `journal_mode=WAL` + `busy_timeout=5000`; index `idx_messages_conversation_id ON messages(conversation_id, id)` va `idx_process_entries_user ON process_entries(user_id, performed_at DESC, id DESC)`.
- **Auth**: express-session + **SQLite session store tu viet** (`session-store.js`, song sot qua restart). Socket handshake xac thuc bang `?sessionId=` (tra ve tu /api/login) qua cung store. Login cap session id moi (`req.session.regenerate` + `save`) chong session fixation.
- **Upload**: multer → `public/uploads/`, toi da 5MB, whitelist phan mo rong (jpg/png/gif/webp/pdf/doc/docx/webm/ogg/mp3/wav/m4a) + **kiem tra magic bytes** chan file gia mao dinh dang. Tin nhan thoai ghi truc tiep bang MediaRecorder roi upload qua cung endpoint.
- **Rate limit** (`rate-limit.js`, cua so truot trong bo nho): socket message 8 tin/10s/user; login 20/5 phut/IP; register 10/10 phut/IP; upload 30/10 phut/user.
- **Env**: `dotenv` doc `.env` (mau tai `.env.example`); bien trong shell duoc uu tien. Bot LLM: `LLM_PROVIDER` (off|gemini|openai, mac dinh gemini khi co key), `LLM_API_KEY`, `LLM_MODEL` (mac dinh gemini-3.1-flash-lite), `LLM_BASE_URL` (OpenAI-compatible: DeepSeek/Ollama...). **API fallback**: `LLM_FALLBACK_PROVIDER` (mac dinh off), `LLM_FALLBACK_API_KEY`, `LLM_FALLBACK_MODEL`, `LLM_FALLBACK_BASE_URL` (vi du Groq `https://api.groq.com/openai/v1`) — LLM chinh loi/qua tai/timeout/reply rong thi bot thu API fallback truoc khi ve rule-based. **API fallback 2**: `LLM_FALLBACK2_PROVIDER/API_KEY/MODEL/BASE_URL` (mac dinh base Groq `https://api.groq.com/openai/v1`, model `gpt-oss-120b`) — thu sau fallback 1. **Gio hanh chinh bot**: `OFFICE_HOURS` (mac dinh `8-17`, end-exclusive, `0-24` = luon trong gio) — ngoai gio bot khong goi LLM/KB ma tra `OFFHOURS_REPLY`. Khong co key → bot chay rule-based offline. **Job don rac uploads**: `UPLOAD_CLEANUP_INTERVAL_HOURS` (mac dinh 24; 0 = tat) + `UPLOAD_CLEANUP_MIN_AGE_HOURS` (mac dinh 24 — chi xoa file cu hon muc nay).
- **Bot engine** (`bot.js` + `knowledge-base.js` + `reply-cache.js`): matching keyword tieng Viet 2 tang whole-word (normalize NFD strip dau, d→d, collapse khoang trang); boolean scoring (compound match bat ky = 3 diem thang tuyet doi, single = 1 khi khong co compound, thu tu mang KB quyet dinh khi hoa). LLM SSE streaming bang native fetch (Gemini `:streamGenerateContent?alt=sse` + systemInstruction; OpenAI `/chat/completions` stream:true), AbortController 25s, history 14 tin cuoi (500 ky tu/tin), reply toi da 1200 ky tu, SYSTEM_PROMPT co guard chong prompt injection. **Cache cau tra loi LLM** (`reply-cache.js`: LRU 200 entry + TTL 24h, key = normalize cau hoi cuoi cua khach) — cau hoi lap lai dung lai cau tra loi cu khong goi API (tiet kiem token); chi cache khi LLM thanh cong, `onDelta` phat ca cau tra loi 1 lan.
- **Frontend**: HTML5, CSS3, Vanilla JavaScript thuan (khong dung build tools/bundler). Theme Zalo blue `#0068FF` (bubble cua minh xanh nhat #e5efff chu toi, bubble doi phuong trang, header trang, o nhap pill + nut gui tron xanh, nen chat xam nhat #e9eff7).

## 3. Cau truc thu muc
- server.js: Entry point (session, socket events, page guards /chat /admin /partner theo role). Security headers co ban (nosniff / SAMEORIGIN / referrer-policy). **CSRF middleware global tren `/api`**: method ≠ GET/HEAD/OPTIONS, bo qua `/login` + `/register`, request chua dang nhap thi di tiep (de requireAuth tra 401), con lai goi `requireCsrf` (403 neu thieu/sai token). Handler `message`: cap do dai 4000 ky tu; attachment URL phai bat dau `/uploads/`, khong chua `..` va file phai ton tai trong `public/uploads/` (neu khong → strip, chan tracking pixel + path traversal). **Bot**: `triggerBotReply(conversation)` duoc goi cuoi handler message khi `conversation.kind === 'user_admin' && user.role === 'user' && conversation.bot_enabled === 1` — emit `typing` (name "Tro ly AI") → cho `BOT_THINK_MS` 700ms → `generateReply(history, onDelta)` emit `bot-stream {convId, delta, clientId}` → `insertMessage` as bot → emit `message` cuoi senderRole='bot' + cung clientId → `typing` false. `botBusy` Set theo conversation chong tra loi trung; bot khong di qua handler socket (khong bi rate limit), khong tao unread badge. Truoc khi goi LLM/KB, server kiem tra `isOfficeHoursNow()` — ngoai gio (env `OFFICE_HOURS`) tra thang `OFFHOURS_REPLY` (via 'offhours', van stream tung cum); neu `reply.unsure` (bot khong chac) thi emit `bot-unsure {convId, userId, userName, preview}` toi room `admins`. Handler `read`: moi role deu duoc danh dau da doc ben cua minh (`markAsRead(convId, userSide)` — userSide=true voi user hoac partner trong partner_admin, false voi admin hoac partner trong partner_user) → emit `read-by {convId, userId, userSide, seenUpTo}` vao phong `conv_<id>` de ben kia hien nhan "Da xem"; admin doc thread user_admin/partner_admin con emit `badge-cleared`/`partner-badge-cleared`.
- db.js: Schema SQLite + migration + helpers:
  - `conversations.kind`: `user_admin` (khach↔admin, 1/user), `partner_user` (khach↔partner), `partner_admin` (partner↔admin, theo cap khach/partner). Partial unique index thay cho UNIQUE(user_id) cu (migration rebuild bang).
  - `conversations.bot_enabled INTEGER NOT NULL DEFAULT 1` (migration ALTER TABLE neu thieu) + `conversations.user_last_read_id INTEGER NOT NULL DEFAULT 0` (moc doc ben khach/user, migration ALTER voi guard `kind` da co). User ao bot `ai-bot` (username 'ai-bot', role 'bot', display_name 'Tro ly AI', hash bcrypt ngau nhien, bi loai khoi danh sach admin `WHERE role='user'`); `setBotEnabled(convId, enabled)`, `getBotUser()`.
  - `getMessagesPage(convId, beforeId, limit)` → `{ messages, has_more }` (trang moi nhat truoc, sap cu → moi); `getMessagesAround(convId, targetId, limit)` → nua truoc (id ≤ target, DESC) + nua sau (id > target, ASC) gop ORDER BY id ASC, `has_more` = con tin cu hon tin dau trang; `searchMessages(convId, q, limit=30)` (LIKE tren content + attachment_name, callers escape `%`/`_`/`\`, moi nhat truoc).
  - `getOrCreatePartnerThread` / `ensurePartnerThreads(userId, partnerId)`: tao/lay 2 thread rieng cua partner.
  - `canAccessConversation(user, conversation)`: admin → user_admin + partner_admin (khong vao partner_user); user → user_admin/partner_user cua minh (khong vao partner_admin); partner → 2 thread partner cua khach dang duoc gan (kiem tra lai user_admin.partner_id), khong vao user_admin.
  - `markAsRead(convId, userSide)` / `countUnread` / `countPartnerUnread`: 2 watermark `admin_last_read_id` + `user_last_read_id`; `markAsRead` luu moc = id tin cuoi cung cho ben goi va tra ve `seenUpTo` de server ban 'read-by'. Badge do chi dem tin khach trong user_admin sau admin_last_read_id; badge vang (amber) chi dem tin partner trong partner_admin sau admin_last_read_id.
  - Nhat ky: `getProcessEntries(userId)` (toi da 200, moi nhat truoc), `getProcessEntry`, `insertProcessEntry`, `deleteProcessEntry`, `getUserById`.
- session-store.js: Store express-session tren SQLite + getSessionUser() cho socket.
- knowledge-base.js: 12 chu de `{ id, topic, keywords: [[compound],[single]], reply }` — dao-on (Tricyclazole), bac-la, kho-van, ray-nau (Pymetrozine), sau-cuon-la, oc-buou-vang, vang-la, phan-bon, nuoc-tuoi, thuoc-bvtv, gioi-thieu, cam-on + `fallback` goi y ghi nhat ky.
- bot.js: `normalize(text)` (NFD strip dau, d→d, non-alphanumeric→space), `matchPhrase` whole-word token sequence, `ruleBasedReply` boolean scoring, `generateReply(history, onDelta, onFallbackStart)` → `{ text, via, used, unsure }` ('llm' | 'rules'; `used` = 'primary' | 'fallback' | 'fallback2'; `unsure: true` khi cau tra loi la KB fallback → server phat `bot-unsure`) voi LLM SSE streaming, timeout 15s/API, fallback rule-based im lang. `llmStream(history, cfg)` nhan cfg `{provider, apiKey, model, baseUrl}` chay doc lap cho tung API; `thinkingConfig: { thinkingBudget: 0 }` + `maxOutputTokens: 600` (model Gemini 3.x neu khong tat thinking se ngon het budget va cat cau tra loi). `isOfficeHoursNow(now?)` + `OFFHOURS_REPLY` (env `OFFICE_HOURS`, end-exclusive).

## 4. Trang thai hien tai & Luu y
- Ca 3 luong User–Admin–Partner da chay that voi **3 thread rieng tu** (user_admin / partner_user / partner_admin) + **bot AI tra loi tu dong** + **read receipt "Da xem"** + **job don rac uploads** + **cache cau tra loi LLM** + **off-hours/bot-unsure** + **stats 7/30/90 ngay** + **tim kiem chat (search + around)** + **CSRF token**: **E2E 180/180** + **UI check 110/110** (Edge headless).
- UI/UX theme **Zalo blue #0068FF** (login gradient xanh duong + glass card, header chat trang, bubble cua minh xanh nhat #e5efff chu toi, bubble doi phuong trang, bubble bot xanh nhat co dot brand + caret nhap nhay khi stream, nut gui tron xanh icon, nen chat #e9eff7, sidebar item hover/active xanh nhat) + animation: typing indicator realtime, toast thay alert(), avatar chu cai theo role, status ket noi, phan trang lich su, ambient background, timeline nhat ky + empty state dong, drawer truot, tab thread + cham tin moi, sidebar admin co 4 the tong quan + tim kiem khach, bo loc nhat ky + xuat CSV, **modal thong ke (KPI + bieu do cot 7 ngay + donut hoat dong + top khach)**, **lightbox xem anh to** (chat + nhat ky), **am thanh ping + so tin chua doc tren title tab** o ca 3 role, **nhan "Da xem"** tren bubble cua minh khi ben kia da doc thread (read receipt 2 watermark, cap nhat realtime qua `read-by`, auto-read khi mo thread + nhan tin moi). Mau ngữ nghĩa giu nguyen: activity colors, status dot online xanh la, header partner trang voi logo mark amber "Lo trinh tu van".
- Bot AI: user ao `ai-bot` role bot; chi tra loi trong user_admin khi khach nhan va `bot_enabled=1`; admin bat/tat theo tung khach qua toggle UI hoac POST /api/admin/conversations/:id/bot; rule-based offline (12 chu de KB) hoac LLM streaming (env `LLM_PROVIDER`/`LLM_API_KEY`/`LLM_MODEL`/`LLM_BASE_URL`); tin bot khong tao unread badge, khong di qua rate limit socket. **Thu tu tra loi: LLM chinh → LLM fallback (`LLM_FALLBACK_*`) → LLM fallback 2 (`LLM_FALLBACK2_*`) → rule-based.** Khi LLM loi giua chung stream, server emit `bot-stream {reset:true}` de client xoa chu do dang truoc khi fallback go tiep; log `..., API fallback`/`..., API fallback2` khi dung API du phong. Ngoai gio `OFFICE_HOURS` bot tra `OFFHOURS_REPLY` (khong goi LLM/KB); khi cau tra loi la KB fallback (`unsure`) server phat `bot-unsure` toi room admins → admin.js toast 'warn' + ping.
- Security: attachment URL trong tin nhan socket phai la file that su nam trong `public/uploads/` (chan tracking pixel/path traversal), tin nhan cap 4000 ky tu, 3 security headers (nosniff, SAMEORIGIN, referrer-policy), SYSTEM_PROMPT bot co guard chong prompt injection. **CSRF**: token per session (32 byte hex, tao lazy qua GET /api/csrf), middleware global tren /api yeu cau header `X-CSRF-Token` cho moi mutation tru `/login` + `/register`; request chua dang nhap van tra 401 tu requireAuth (khong bi doi thanh 403).
- Tin nhan thoai: ghi bang MediaRecorder o ca 3 giao dien (toi da 60 giay, toi thieu 0.6 giay), tu upload `.webm/.ogg` roi gui ngay; hien `<audio controls>` trong bubble; huy khi doi thread; chip hien dong ho dem. Upload server nhan them mp3/wav/m4a (magic bytes).
- Job don rac uploads (`uploads-cleanup.js`): chay nen 30s sau khi start + moi 24h (env dieu chinh; 0 = tat), xoa file trong `public/uploads/` khong con duoc `messages.attachment_url`/`process_entries.attachment_url` tham chieu va cu hon `UPLOAD_CLEANUP_MIN_AGE_HOURS` (tranh xoa file dang upload do); bo qua dotfile + thu muc con, log so file da xoa. e2e/ui-check tat job nay vi dung chung thu muc uploads voi dev.
- Nhat ky canh tac: bang `process_entries` (activity enum sowing/fertilizing/watering/pesticide/pruning/harvest/other, performed_at YYYY-MM-DD, title, method, details, attachment). User CRUD cua minh; admin xem + xoa duoc; partner chi xem khi da duoc gan. Gioi han 200 muc/khach, toi da 5 tep dinh kem/muc (luu URL don hoac JSON `[{url,name}]` trong `attachment_url`). Drawer user/admin co loc theo hoat dong/khoang ngay/mua vu (mua vu tinh theo thang) va xuat CSV (client-side, khong doi API).
- Chat rieng tu: partner↔khach va partner↔admin la 2 thread doc lap (tao khi admin gan partner). Admin khong thay partner↔khach; user khong thay partner↔admin; partner khong thay user↔admin. Quyen partner bi thu hoi ngay khi admin gan partner khac hoac huy lien ket (kiem tra user_admin.partner_id moi lan access). **Huy lien ket**: header admin co nut danger "Huy lien ket" canh chip "Đã kết nối" — click → `confirm()` xac nhan → POST `/api/admin/conversations/:id/disconnect` → partner_id = NULL (giu thread + lich su), chip/select chuyen trang thai, tab partner an; gan lai se tai su dung 2 thread cu.
- Tai khoan seed: **admin/admin123**, **partner1/admin123**, **user1/user123** (luu y: partner1 dung hash cua admin123). Trang login co 3 nut "Vao nhanh" bam la dang nhap luon (van goi /api/login voi thong tin seed, khong mo endpoint passwordless).
- Session persist qua restart (cookie + sessionId). Login regenerate session id moi.
- Socket event contract: client → `join {convId}`, `message {convId, content, attachment?, clientId?}`, `read {convId}` (moi role, danh dau doc ben minh), `typing {convId, isTyping}`; server → `joined`, `message` (echo clientId, kem senderRole), `read-by {convId, userId, userSide, seenUpTo}` (ben kia da doc → hien "Da xem" cho tin cua minh co id ≤ seenUpTo), `unread-badge`, `badge-cleared` (thread user_admin), `partner-badge`, `partner-badge-cleared` (thread partner_admin), `user-message` (room `admins`, kem senderRole), `partner-message` (room `admins`, tin partner trong partner_admin), `typing {convId, userId, name, isTyping}`, `bot-stream {convId, delta, clientId}` (bot dang tra loi, room `conv_<id>`), `bot-unsure {convId, userId, userName, preview}` (room `admins`, bot khong chac → nhac admin), `process-updated {userId, userName, convId, action, entryId}`, `error`. Moi `join`/`message`/`read` deu qua `canAccessConversation`; client join tat ca thread cua minh luc connect de nhan realtime.
- Secret session: env `SESSION_SECRET` (co gia tri mac dinh cho dev).
- Unread: `admin_last_read_id` la watermark id tin theo tung conversation; badge do dem tin khach sau watermark trong user_admin; badge partner (amber) dem tin partner sau watermark trong partner_admin. `user_last_read_id` la watermark ben khach/user — chi dung cho read receipt "Da xem" (khong lien quan badge admin).
